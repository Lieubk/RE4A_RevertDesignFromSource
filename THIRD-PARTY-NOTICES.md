## External tools invoked at runtime (NOT distributed with RE4A)

RE4A can optionally invoke the following programs as separate, user-installed processes
(command-line invocation only; no linking). They are **not** part of the RE4A distribution
and their licenses impose no obligations on RE4A itself. Do not bundle them into the RE4A
installer without a separate licensing review. DOCX generation itself is fully built-in
(Open XML SDK) and requires none of these; they are only needed to render PlantUML diagrams
into embedded images.

| Tool | License | Note |
|---|---|---|
| PlantUML | GPL-3.0 (default jar) | Diagram rendering. MIT/Apache/LGPL/EPL editions exist ("plantuml-mit"); prefer those if bundling is ever required. Images generated by PlantUML are owned by the diagram author and are not covered by GPL. |
| Java runtime (for plantuml.jar) | e.g. Temurin: GPLv2 + Classpath Exception | User-installed. |
| Graphviz (used by PlantUML for some layouts) | EPL-1.0 | User-installed; optional. |
